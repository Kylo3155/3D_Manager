# 3D_Manager

Sistema web para administrar un negocio de impresion 3D. Permite registrar impresoras, filamentos e insumos, llevar pedidos con modelos, actualizar stock automaticamente y controlar ingresos, egresos y ganancias. Incluye una calculadora de presupuestos.

## Como usarlo

1. Ejecuta el script de inicio:

```bash
bash scripts/run_dev.sh
```

2. Abre la pagina en tu navegador:

```text
http://127.0.0.1:8000/
```

3. Usa el menu de la izquierda para navegar entre secciones.
